# 周期判断方法

> 浓缩自 serenity-skill 的 juglar-cycle-stock-stage（原版见 `.context/serenity-skill/skills/juglar-cycle-stock-stage/`）。本文件用于"行业/环节级"判断，不做个股定价。

## 1. 三重验证（快速过筛）

一个环节值得深挖，通常至少满足两条：

1. **需求爆发**：订单、出货量、进口量、下游资本开支在真实增长（不是"预期增长"）
2. **供给受限**：产能被垄断/管制/认证墙/扩产周期锁住，短期无法放量
3. **技术跃迁**：架构/路线迁移重新洗牌供应链（既是机会也是风险——旧路线逻辑可能被绕过）

## 2. 朱格拉周期五阶段

| 阶段 | 特征信号 |
|---|---|
| Stage 1 复苏期 | 需求改善、价格止跌、库存下降、毛利修复、资本开支尚未启动 |
| Stage 2 扩张期 | 订单强劲、收入利润加速、产能利用率上升、资本开支开始增加 |
| Stage 3 过热期 | 价格毛利双高、情绪乐观、企业激进扩产、未来供给风险累积 |
| Stage 4 衰退期 | 需求放缓、价格松动、库存上升、毛利下滑、资本开支削减 |
| Stage 5 出清期 | 行业亏损逼出产能出清、去库存、关停、并购整合 |

**判断时优先看四个核心变量：毛利率、资本开支、库存、价格。** 不要从股价/PE/故事倒推阶段。

可观察证据清单：订单/backlog、产能利用率、产品价格与合同价、库存与渠道库存、行业扩产公告、客户抢单/长协/砍单行为、券商盈利预测修正方向。

## 3. 三个"阶段"必须分开

同一时点三者经常背离，报告里必须分别标注：

- **行业周期阶段**（基本面在周期哪个位置）
- **公司经营阶段**（具体环节的产能/认证兑现进度）
- **市场定价阶段**（股价/估值已经按哪个阶段在定价）

例：行业 Stage 2，但市场已按 Stage 3 定价 → 环节是真的，但赔率已经不行。对 A 股尤其重要：**"真卡脖子 + 已被爆炒"是排除项，不是加分项**。

## 4. 阶段判断对输出的影响

| 周期位置 | 输出结论倾向 |
|---|---|
| 复苏期 + 定价未反映 | 最佳：重点推荐关注 |
| 扩张期 + 定价部分反映 | 可关注，提示估值 |
| 过热期 / 定价已充分 | 排除或仅观察，写明"逻辑真但赔率差" |
| 衰退/出清期 | 排除；除非判断出清接近尾声（反向布局需更强证据） |

## 5. 迁移信号

给出"什么证据会让阶段判断移到下一阶段"：如下游 capex 拐点、库存拐点、价格拐点、大厂扩产/减产公告、政策变化（出口管制加码/放松）。这些同时就是证伪/强化条件的素材。
