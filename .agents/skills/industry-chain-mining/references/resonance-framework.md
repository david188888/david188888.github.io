# 基本面共振判别（Lollapalooza / L-共振）

> 服务**行业/环节级**与**公司级**。把现有"多因子并列罗列"升级为"多因子共振判别"：主攻识别**多重利好同向叠加**的超额机会，并用**反向共振**防价值陷阱。
> 概念来源：芒格 Lollapalooza Effect——多个**相对独立**的因素同时**同向**作用，产生非线性放大。本文件把这一思想**落到基本面因子**，不扩展到心理学/情绪层面。

## 0. 何时用

- **环节筛选 / 深挖**（行业级，Step 3/4）：判断哪个环节正形成真共振，值得作为主攻/ETF 方向。
- **候选公司线索卡**（公司级，初筛后、进手册 Step 2/3 前）：判断公司是否形成超额空间共振。
- **手册 §2.3 多利空反向共振条款**、**一页纸 Lollapalooza 共振档案**的底层方法（本文件是它们的判别逻辑来源）。

## 1. 六类独立因子（T1–T6）

设计原则：尽量**相互独立**，避免同类信号互相印证而重复计数。

| 编号 | 因子 | 覆盖信号 | 判断方向所需证据 |
|---|---|---|---|
| T1 | 周期位置 | 朱格拉阶段、价格/库存/资本开支/毛利拐点、产能利用率 | 行业价格、库存、资本开支、毛利；不要从股价/PE 倒推 |
| T2 | 供需格局 | 需求爆发性、供给受限/卡脖子、产能出清 | 订单/backlog、出货、产能、认证墙、扩产周期、大厂增减产 |
| T3 | 政策与产业趋势 | 产业政策、补贴/退坡、出口管制（双向）、标准/技术路线、国产化率 | 政策原文、标准落地、技术路线迁移证据 |
| T4 | 业绩兑现 | 收入/利润/现金流/毛利率真实趋势与确定性 | 财报、业绩预告、经营数据；区分"已兑现"与"预期" |
| T5 | 竞争格局与护城河 | 市占率、议价力、认证壁垒、技术代差、客户结构 | 龙头份额、认证/定点名单、技术代差 |
| T6 | 估值与预期差 | 估值分位、与市场定价阶段的差、情绪是否已计入 | PE/PB/PS 历史分位、相对行业/同业比较、市场已按哪个阶段定价 |

> 事件/催化（政策发布、大单公告、产能投产）一般归入 T3 或 T2/T4，不单设一类；资金面/情绪面属"市场认知层"，本框架不做基本面共振主体，仅在 T6 用"定价是否已计入"交叉。

## 2. 步骤 A｜拆因子 + 同源合并（防伪共振）

1. 列出当前**所有**看多 / 看空信号（来自需求判断、周期判断、多空对照等）。
2. **归并同源**：多个信号若出自同一底层原因，只算一类。例：
   - "需求爆发" + "涨价" + "订单增长"+ "产能利用率上升" 若均因下游扩产一个源 → 归并到 T2 一类，**不重复计数**。
   - "毛利下滑" + "价格松动" 若同源于供给过剩 → 归并 T1，不计两次。
3. 合并后计数 = **有效独立因子数**。此为真共振/伪共振的分野。

> 伪共振定义：表面"6 个利好"，合并后仅 1–2 类独立因子 → 不构成共振，是**单因子机会**，按普通机会处理，不得评为"超级机会"。

## 3. 步骤 B｜同向递进判别

逐类判定方向 **多（+）/ 空（-）/ 中性（0）** 并记**强度**（强/中/弱），依据步骤 A 已合并后的独立因子。

| 判定 | 条件 | 结论 |
|---|---|---|
| **真共振（机会）** | ≥3 类独立因子同向为多，且无强反向因子 | 超额空间信号，可列为重点；但仍需步骤 C 定价交叉 |
| **伪共振** | 表面多但多数同源，合并后 ≤2 类独立 | 单因子机会，按普通处理 |
| **反向共振（风险）** | ≥3 类独立因子同向为空 | 价值陷阱/恶化信号，触发手册 §2.3 升级处理（降级/剔除/强制复核），即使估值低 |
| **方向分裂** | 多空因子并存、强度接近 | 共振未形成或正在瓦解，降低可信度，谨慎 |

> 反向共振与"估值低"不冲突：**低估值 + 多条独立利空共振 = 价值陷阱**，正是"低却涨不回"的成因，需升级处理而非因便宜而买入。

## 4. 步骤 C｜共振阶段 + 定价交叉 + 瓦解观察

### 4.1 共振阶段
| 阶段 | 特征 | 对赔率的意义 |
|---|---|---|
| 启动 | 独立因子刚开始转多，市场尚未充分定价 | 最佳介入窗（赔率最好） |
| 加速 | 因子持续强化，业绩/景气确认，定价逐步跟上 | 仍可持有/加仓，但更靠近兑现 |
| 衰减 | 部分因子转弱/反向，价格已充分甚至透支 | 通常该兑现收益，也是止盈/认错预警 |

### 4.2 定价交叉（复用 cycle-judgment 的三阶段经验）
判断"共振是否已被市场计入"：
- **真共振 + 定价未充分反映** → 最佳超额机会，重点推荐。
- **真共振 + 已爆炒（估值分位高、短期大涨）** → 逻辑真但**赔率差**，排除或仅观察。
- 注意：行业/经营/定价三阶段要分开标注，避免"行业启动但股价已炒到过热"仍当推荐。

### 4.3 瓦解观察指标（认错 / 止盈预警）
每类独立因子抽 **1 个可观察先行指标** 作为共振瓦解的哨兵：

| 因子 | 瓦解哨兵示例 |
|---|---|
| T1 | 库存/价格拐点、资本开支异常放量、毛利连降 |
| T2 | 大厂扩产/复产、产能利用率回落、订单转弱 |
| T3 | 政策收紧/补贴退坡、管制方向反转、技术路线被绕过 |
| T4 | 收入/现金流增速转负、毛利率连降、业绩预告下修 |
| T5 | 份额被蚕食、价格战、核心客户流失、认证被替代 |
| T6 | 估值分位越上沿、情绪过头（拥挤/大资金撤离）、与定价阶段背离 |

## 5. 输出形式（环节卡片 / 公司线索卡用）

在"多空对照"之后加一段精炼的 **L-共振判别**：

```markdown
### L-共振判别
- 独立因子方向：T1 周期[多/空/0-强度] · T2 供需[...] · T3 政策[...] · T4 业绩[...] · T5 格局[...] · T6 估值[...]
- 同源合并：哪些信号同源已归并（不重复计）→ 有效独立因子数
- 结论：真共振（≥3独立同向多）/ 伪共振（同源堆多）/ 反向共振（≥3独立同向空）/ 方向分裂
- 阶段：启动 / 加速 / 衰减
- 定价交叉：共振是否已被计入 → 赔率好/差
- 瓦解哨兵：[各因子关键哨兵]
```

## 7. 警惕（防自欺）

- **别为"想买"而把中性信号标成多**（确认偏误）。
- **"叙事/预期/涨价"≠已发生的共振**：需要订单、公告、报表证据，没有就降级。
- **单因子≠超级机会**：只有 ≥3 类独立同向才是共振，普通机会不要拔高。
- **同源合并是硬动作**：不合并就会高估共振强度，导致追高。
- **反向共振不要因便宜而放过**：价值陷阱往往"看起来低、实际在恶化"。
