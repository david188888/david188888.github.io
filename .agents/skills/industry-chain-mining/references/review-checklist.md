# 自我审查清单（输出前强制执行）

> 源自 Notion 参考报告"审查修正"环节的方法论沉淀 + serenity 体系的 Source Discipline。审查发现必须写进报告"自我审查记录"。

## 1. 确认偏误检查（最重要）

- 我是否为了让"结论成立"而选择性筛证据？（经典翻车：一边把某环节定为最硬卡脖子，一边把"唯一已兑现该环节的公司"踢出名录，只留下还在送样阶段的——因为"小盘高弹性"的故事更好讲）
- 每个看多论点，我是否主动找过反面证据？
- 结论是否恰好是"我/用户本来想听到的"？

## 2. 证据质量检查

- **孤证**：只有单一来源的数字降级为〔需谨慎〕，不作强论据
- **口径**：同比 vs 环比 vs 累计涨幅分清；整机 vs 零部件、整体 vs 细分的国产化率口径注明；台数 vs 金额分清
- **时效**：超过 1 年的市占率/国产化率/估值快照不得描述为"当前"（替代在快速发生，旧低份额会夸大"剩余空间"）
- **绝对化表述**："唯一""第一""空白"必须验证——经常是把两个不同事实拼接出来的（如"全球三家量产"+"某环节认证"拼成"唯一通过认证"）
- **口径拼接**：两个真实事实拼在一起会得出一个假的"唯一性"

## 2.5 推论证据回溯检查

- 文章或报告的每个重大推论是否紧邻事实依据，而不是只在文末列来源
- “行业会爆发”是否被拆成需求量、采购/付费、技术可用性或供给约束中的至少一个可观察事实
- “成本已经下降到瓶颈”是否有时间序列、价格、BOM 或 TCO 证据；规格变化不等于成本事实
- “Agent-to-Agent 将成为主流”是否明确标为预测，并列出现有部署、协议、调用数据和证伪信号
- 用户观点与外部事实是否清晰区分
- “当前”“已实现”“已量产”“已普及”等词是否有时点和范围
- 资本开支、融资、合同和装机量是否被误当作有效需求、利用率或现金流

## 3. 逻辑方向检查

- "我卡别人"（中国出口管制）≠"别人卡我"（国产替代）——方向相反，不能混用
- 全球同缺 ≠ 国内独享机会
- 市场涨价 ≠ 公司利润兑现（需要订单/公告/报表证据；公司明确说"尚未签署大额订单"时，涨价叙事直接降级）
- 技术替代尾部风险：被卡的材料/路线本身可能被新技术绕过（如钼替代钨、CPO 绕过 EML）

## 4. 排除规则执行检查

- 是否对每个"看起来很性感"的环节/公司跑过 `screening-rules.md` 的排除清单？
- 是否把"真逻辑 + 已爆炒"的环节诚实排除，而不是因为喜欢逻辑就留下？
- 旧印象是否过时？（"某公司题材占比低"的判断可能已被最近年报改变——用最新收入结构，不用记忆贴标签）

## 5. 完整性检查

- 每个环节是否都有证伪条件（可观察、可检验、有时间窗）？
- 行业周期阶段 / 公司经营阶段 / 市场定价阶段是否分开标注？
- 数据来源是否列出（名称 + 日期）？
