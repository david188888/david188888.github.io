# 公司线索发现工具链（Step 4 前置）

> 解决的问题：线索名单**怎么找**，而不是怎么筛（筛选见 `screening-rules.md`）。
> 原则：**候选公司必须来自可验证来源，禁止仅凭模型记忆列名单**。记忆只能用来"想起还有哪些渠道/关键词"，不能直接当出处。

## 数据源分工（2026-08-20 用户定：免费源优先）

- **主用：a-stock-data**（本地 skill `a-stock-data`，GitHub simonlin1212）。免费、零 Key（仅 iwencai 语义搜索需 Key），覆盖行情/估值/财务三表/F10/公告/解禁/减持/分红。端点路由见其 SKILL.md「端点路由速查」表；源码不复制到本文，用哪端点读哪节。
- **兜底：Wind MCP**（本地 skill `wind-mcp-skill`，CLI 调用）。仅在以下情况启用：a-stock-data 端点缺失/失败/返回字段不全（如扣非口径）/ 数据明显异常需权威复核。**消耗 Wind 积分，调用要克制**（先宽条件一次拿，不逐家闲聊式查询）。
- L2 补池：WebSearch（见 L2 节），两数据源都替代不了。

调用纪律（a-stock-data 侧，源自其 SKILL.md 防封铁律）：

- 行情/估值/财务优先走**不封 IP 的源**：mootdx（通达信 TCP）、腾讯财经、新浪、baostock。
- **东财端点必须走 `em_get()` 限流**（串行、间隔≥1s+抖动），批量逐家调用时每只之间 sleep——批量循环是被封 IP 的头号元凶。
- 东财只用于其独有数据：解禁日历、股东户数、分红、概念归属、资金流等。

## 三层漏斗

```
L1 建池（求全）→ L2 定向检索（补缺）→ L3 逐个验证（求真）→ 进入 screening-rules.md 筛选（排除规则 + 数值初筛）
```

### L1 建池

把"该环节有哪些上市公司"从回忆题变成查询题。

- **首选（有 `IWENCAI_API_KEY` 时）**：a-stock-data §2.3 `iwencai_query("{环节}概念股")` / `iwencai_query("主营业务包含{细分产品}的沪深股票")`——问财语义选股，一次建池。
- **无 iwencai Key 时**：L2 WebSearch 直接承担建池（多查几组关键词，见下），不因此去调 Wind。
- **Wind `search_stocks` 仅作补充**：上述两路池子明显偏薄（如 ≤3 家且怀疑漏网）时才用，查询模板 `"筛选沪深市场属于{概念名}概念的股票"`（CLI 用法见 wind-mcp-skill `references/stock.md`）。
- 一个环节可拆 2-3 个查询（概念 + 主营 + 上位行业），合并去重得到初始池。

### L2 补池：定向检索

板块/概念分类粗糙，卡脖子细分环节（如"KrF 光刻胶"而非整个"光刻胶"板块）常有漏网。用 WebSearch 补：

- 查询模板：`"{细分环节} 国产替代 上市公司 厂商"`、`"{细分环节} 龙头 产能 {当前年份}"`、`"{细分环节} 产业链 梳理 研报"`
- 优先信源：券商研报、上市公司公告/互动易、行业协会数据；自媒体只作线索不作证据。
- 检索到的公司必须标注来源，且仍要过 L3。

### L3 逐个验证（提纯，每个候选都要过）

对 L1+L2 池子里拟列入名单的每家公司，用 **a-stock-data 优先**验证四件事：

| 验证项 | 首选端点（a-stock-data） | 判什么 |
| --- | --- | --- |
| 业务纯度 | §3.3 `eastmoney_concept_blocks`（概念归属）+ §6.2 mootdx F10（主营构成文本） | 题材是不是主营；占比存疑时 §6.4 新浪利润表查分产品营收 |
| 兑现状态 | §7.1 `cninfo_announcements`（公告）+ §10.1 `cninfo_irm`（互动易）+ WebSearch | 已量产 / 验证中 / 送样，区分"已发生"与"故事" |
| 权限板块归属 | 直接看代码：60/00 = 沪深主板、30 = 创业板、688 = 科创板 | 688 → 标〔科创板，权限不可买，仅作板块观察〕（用户当前无创业板权限，30 开头按手册 §1 处理：标注〔创业板，暂不可买〕） |
| 排除规则结构化项 | §6.5/§6.6 baostock（ST/上市日/退市日）、§3.6 `lockup_expiry`（解禁）、§6.4 新浪利润表（连续亏损） | 对应 `screening-rules.md` §2 各条 |

**Wind 兜底**：上表任一项 a-stock-data 取不到/字段存疑时，用 Wind 对应工具复核（`get_stock_basicinfo` / `get_stock_fundamentals` / `get_stock_events` / 公告），遵循 wind-mcp-skill 批量纪律（先发 1 家探针，成功再续；`circuit_breaker.tripped` 或 `BLOCKED_QUOTA` 时终止本批并标注缺口）。

L3 通过后进入 `screening-rules.md`：先过 §2 排除规则，再过 §2.5 数值初筛（手册 §2.1 分层执行版）。

## 纪律

- 线索卡"备注"列必须能看出出处类型：iwencai / 研报 / 公告 / Wind。说不清来源的公司不进名单。
- 名单 ≤5 家/环节的上限不变；L1 池子大不是多列的理由，是用来**挑**的。
- 数据时点标注规则不变：筛选结果、量产状态等以查询当日为准，报告中写明"截至 YYYY-MM-DD"。
- 引用 Wind 数据处标注"数据来源于万得 Wind 金融数据服务"；引用免费源处标注实际来源（腾讯/新浪/东财/baostock/巨潮等）。
