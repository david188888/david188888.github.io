# GA4 站内私人看板

用户已确认使用「自建看板 + 浏览器 Google 只读授权」，并授权协助完成 Google Cloud 配置。

## 范围

- `/stats/` 与中英文统计页直接显示真实 GA4 数据；保留外部 Google 看板链接和可选文章作者工具。
- 同一个媒体资源 `525415859` 汇总全站页面，展示所选 7/30 天的浏览次数、活跃用户、会话、每日浏览趋势、热门页面和来源渠道；另列最近 30 分钟活跃用户。
- GitHub Pages 静态部署不变，不新增后端、不发布统计 JSON、不保存 Google 访问令牌到 localStorage/sessionStorage、URL 或构建文件。

## 数据与授权

- Google Cloud 项目：`david-homepage-analytics`，项目编号 `486642833218`。启用 Analytics Data API；配置 Web OAuth 客户端，正式来源 `https://david188888.github.io`，本地测试来源按实际端口配置。
- 网站使用 Google Identity Services 的 token model，仅请求 `analytics.readonly`。Google 授权弹窗由用户点击触发，授权成功后访问令牌仅留在当前页面内存，过期/断开时清除令牌和私人报表数据。
- OAuth Client ID 是公开配置，通过 `NEXT_PUBLIC_GOOGLE_ANALYTICS_CLIENT_ID` 在构建时注入；不使用客户端密钥。未配置、库加载失败、拒绝授权、权限不足、额度/网络错误、已过期均有明确状态，不显示伪造的零或示例数字。
- 一次 `batchRunReports` 请求分别获取区间总计（不按日/页面相加去重用户）、每日浏览量、热门页面和渠道会话；实时请求独立，实时失败不抹掉有效历史报表。
- 相对日期范围由 GA4 媒体资源时区解释；UI 标注报表时区与最后获取时间。日期图只使用有效返回日期，空成功响应显示「暂无数据」；缺失/损坏响应报错，不转成零。
- 切换范围、断开、令牌过期和卸载会取消旧请求。较晚返回的旧范围或旧连接结果不得覆盖新状态。

## 界面

- 头部保留站点与全站口径说明，主操作为「连接 Google」；连接后提供范围选择、刷新、断开。
- 四个指标区域分别为浏览次数、活跃用户、会话和近 30 分钟活跃用户。历史与实时使用明确不同的范围标签。
- 简单 SVG 趋势图配可读的数据列表；热门页面/来源使用原生列表或表格和比例条。沿用当前主题变量，不引入大型图表依赖。
- 窄屏垂直排列、长路径换行，键盘和屏幕阅读器可读取所有数值。加载/错误/过期状态均保留外部报表入口。
- 不自动循环刷新；用户点击刷新后请求最新报表，避免无意义消耗配额。
