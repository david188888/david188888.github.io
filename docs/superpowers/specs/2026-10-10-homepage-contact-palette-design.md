# 首页联系入口与配色说明

用户已确认布局和说明文案，并授权制作实际页面与可交互预览。

## 目标与范围

保留当前暖纸白／酒红与炭黑／柔玫瑰配色，以留白和清楚的入口层级表达舒服、沉稳、低调的气质。只调整首页首屏个人链接、底部联系区与页脚，不改变其他页面的主题行为或正文内容。

## 布局与内容

- 首屏保留简历、GitHub、Google Scholar，移除直接邮件入口；顶部「联系」仍跳转到 `#contact`。
- 底部口号独立一行，完整邮箱放在下一行；移除重复的简历、GitHub。
- 页脚左侧为三枚小色样与「关于配色」按钮，右侧保留版权文字。手机端自然纵向排列。
- 点击配色入口打开轻量原生模态对话框，包含个人选色说明及深浅色的色样、名称和色值；中英文语义保持一致。
- 中文说明：我希望这个网站给人的第一感受是舒服、沉稳、低调。浅色用接近纸张的暖白，深色用安静的炭黑，再以酒红色点出少量重点。它们有温度，也有分寸。我希望文字与思考被看见，也让人愿意停下来，慢慢读。

## 实现与交互

独立客户端组件 `EditorialPaletteNote` 管理对话框；首页保持服务端渲染。使用原生 `dialog.showModal()` 保持焦点约束、Escape 关闭及关闭后焦点恢复。关闭按钮和点击背景均可退出，打开期间锁定页面滚动，关闭或卸载时恢复。对话框有可访问名称与说明，色样同时提供文字，禁止仅依赖颜色。所有样式在 `.ed-root` 下隔离，继续使用既有主题 token，不增加换肤选项。

## 验证与预览

运行全部 Vitest 和静态构建；真实浏览器检查中英文、深浅色、390px 与320px布局、打开关闭、Escape、焦点恢复及横向溢出。保留本地预览服务并在 Codex 打开页脚位置，同时提供入口与展开态截图。保留所有既有无关工作区更改。用户确认预览后已追加 GitHub 发布授权：从最新主分支创建独立分支，仅提交本次文件，经 PR 检查后合并，并独立验证 Pages 部署及线上页面。
